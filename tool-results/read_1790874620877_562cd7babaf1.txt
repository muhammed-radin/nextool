     3→Project: Build NexTool Q1 v1.0.0 per spec in `/home/z/my-project/upload/Pasted Content_1790827341994.txt` (81 sections).
     4→Spec summary: NexTool is NOT a chatbot/LLM wrapper UI — it is a real task-processing, planning, observation, automation & tool-execution system:
     5→- Main orchestration loop: UNDERSTAND → PLAN → SELECT TOOL → GENERATE PARAMS → EXECUTE → OBSERVE → UPDATE STATE → REPLAN → COMPLETE
     6→- Goal Mode (default, finite) + Live Mode (explicit, scheduled + event-driven, interruptible)
     7→- CoreModule: dynamic tool matching (no hardcoded tool ids), extractive + constructive parameters, confidence, structured JSON output (tool_call | no_tool | clarification_required | cannot_execute | stop)
     8→- Tool Runtime: async, parallel for independent ops, dependency-aware, timeout/failure/cancel states
     9→- Persistent Memory ≠ Live State; Context = previous + delta + observation + memory + history
    10→- Runtime limits (maxIterations, maxToolCalls, safetyLimit, timeouts); cancellation
    11→- Real event streams to frontend (NO fake data anywhere — honest empty/unavailable states allowed)
    12→- Next.js console: Dashboard, Task Console, Task Preview (dedicated), Live Monitor, Tools, Memory, Live State, Context, Events, History, Models, Datasets, Settings
    13→- Style: AI Operations Console / Developer Control Center — technical, minimal, precise. Not ChatGPT-like.
    14→
    15→## Sandbox constraints (binding)
    16→- Next.js 16 App Router, TypeScript, Tailwind 4, shadcn/ui (New York), Prisma+SQLite, z-ai-web-dev-sdk (BACKEND ONLY)
    17→- ONLY route `/` is user-visible (src/app/page.tsx). All 13 console screens must be client-side views inside one page (SPA shell). No other page routes.
    18→- API routes for backend (no server actions). SSE allowed for real-time streaming (spec allows WebSocket OR SSE — using SSE for sandbox reliability).
    19→- No test code. Footer (status bar) must stick to bottom (min-h-screen flex flex-col + mt-auto). No blue/indigo colors — use zinc neutrals + emerald primary + amber/red statuses (dark ops-console theme).
    20→- z-ai-web-dev-sdk: `import ZAI from 'z-ai-web-dev-sdk'`; chat: `zai.chat.completions.create({ messages, thinking:{type:'disabled'} })` (system prompt uses role 'assistant'); images: `zai.images.generations.create({ prompt, size })` sizes: 1024x1024, 768x1344, 864x1152, 1344x768, 1152x864, 1440x720, 720x1440.
